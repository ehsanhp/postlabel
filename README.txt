راهنمای نصب — چاپ لیبل پستی

۱. کل پوشه را روی یک هاست HTTPS قرار دهید (GitHub Pages، Netlify، Cloudflare Pages یا هاست خودتان).
   بدون HTTPS سرویس‌ورکر و نصب PWA کار نمی‌کند (localhost مستثناست).
۲. آدرس را در Chrome (اندروید) یا Safari (آیفون) باز کنید.
۳. اندروید: منو ← Install app  |  آیفون: Share ← Add to Home Screen
۴. یک بار با اینترنت باز کنید تا فایل‌ها ذخیره شوند؛ بعد آفلاین هم کار می‌کند.
۵. تنظیمات ← اطلاعات فرستنده و لوگو را وارد کنید.

نسخه‌ی جدید: مقدار V در sw.js را عوض کنید (مثلاً label-v2) تا کش قدیمی پاک شود.
